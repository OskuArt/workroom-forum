WORK//ROOM — UPDATE 3

1. В PowerShell, где запущен сайт, нажмите Ctrl + C.
2. Распакуйте этот архив.
3. Скопируйте ВСЁ содержимое папки workroom-update-v3 в корень вашей папки САЙТИЩЕ.
4. Windows спросит о замене файлов — согласитесь заменить.
5. .env, node_modules и данные PostgreSQL этот патч не трогает.
6. Запустите сайт снова:

   npm.cmd run dev

7. Откройте http://localhost:3000 и нажмите Ctrl + F5.

ВАЖНО ПРО ВАКАНСИИ:
- При первом запуске после обновления сервер добавит колонку для русского краткого описания автоматически.
- Импортированные короткие описания переводятся на русский в фоне и сохраняются в базе.
- Полное описание вакансии остаётся на языке источника.
- Первый проход перевода может занять некоторое время в зависимости от интернета; затем переводы берутся из базы и повторно не запрашиваются без необходимости.

Новые npm-пакеты не добавлялись, поэтому npm install повторять не нужно.
